# 数理原典 · 从错题找到下一步

面向高中学生的学习辅助网站，将真实错题、学生解法、知识讲解、前置基础和复核记录连起来。数学、物理保留 7 个探索实验；四学科合计 10 组共 60 道练习。化学新增方程式配平，生物新增基因与遗传概率，均配交互模型。各学科是精选内容，并非完整课程。

## 使用

三个页面共用按学科选课的菜单，只显示所选学科的课程。电脑默认展开：学科 → 课程，两次点击；手机默认收起：选课 → 学科 → 课程，最多三次点击。探索与补强放在同一学科列表，用小标签区分，无需先进入另一个目录。

“我的错题”保持直接入口，API 设置、待补知识、备份及练习摘要收进“学习工具”。课程目录从 `js/curriculum.js` 自动生成，新增课程无需分别修改三套菜单。

打开 `learning.html` 进入错题学习；`index.html` 保留探索实验及明显的错题入口。

1. **录入错题**：选择学科，填写题干和自己的解法，保存。参考答案选填。
2. **关联知识**：点击 AI 分析，或手动选择知识点，核对原文证据和理由。
3. **开始补强**：直接打开对应实验或专项。专项最终复核回写原题，也可重做原题后记录自评。

“三步”指一项操作的流程，不代表全部学习只需点击三次。题目阅读、填写和必要练习不能省略。专项分为定位、按需补强、独立复核三阶段；每题选择答案、选择把握程度、提交即可得到反馈。

| 常用操作 | 路径 |
| --- | --- |
| 配置 API | API 设置 → 填写地址/模型/密钥 → 保存 |
| 从已有错题进入练习 | 打开错题 → 查看关联 → 开始补强 |
| 无 API 的关联 | 展开手动关联 → 选择知识并说明依据 → 保存 |
| 修改错题 | 展开修改 → 修改内容 → 保存（清除旧分析与复核） |
| 查看知识缺口 | 待补知识 → 查看原题或导出清单 |
| 备份 | 点击导出学习备份 |
| 恢复 | 选择备份文件，自动验证后合并新错题 |
| 删除错题 | 打开错题 → 展开删除 → 确认删除 |

## API 与数据

采用 OpenAI 兼容的 `POST /chat/completions`，使用 `model`、`messages`、非流式文本响应；不强制依赖供应商 JSON Schema 扩展。[官方请求格式](https://developers.openai.com/api/reference/resources/chat)。

- 支持基础地址或完整端点，本机允许 HTTP。不会自动猜测厂商路径或模型名称。
- 浏览器直接连接指定服务，服务必须支持当前站点的 CORS。GitHub Pages 无法替服务端修复跨域。禁止请求跳转，密钥通过 Authorization 头发送。
- 保存设置不会发送错题；点击分析才发送当前题目、解法、参考答案和知识目录。测试连接只发送短消息，可能收费。
- 默认密钥保存在当前标签页的 sessionStorage；自愿勾选后明文存入 localStorage，同源脚本可读取，共享设备不应勾选。设置页可忘记密钥。
- 新错题页不加载第三方脚本；原实验页仍使用可选 CDN 数学渲染库，其脚本具有同源页面访问权限。高隐私或多用户部署建议进一步采用自托管资源和服务端密钥代理。
- 错题、练习进度、分析与复核保存在当前浏览器，无账号或自动云同步。清理浏览器数据会丢失记录，请导出备份。备份不含 API 配置或密钥，但含题目原文，请妥善保管。
- 恢复只合并缺少的错题、关联与复核，不覆盖已有错题，不恢复训练运行状态；备份中的 training 数据供检查和后续迁移使用。
- 请求可取消，45 秒超时。失败保留错题及旧分析，不自动重试产生额外调用。

## 知识关联与教学边界

系统练习直接关联表示本题考查范围，不代表已证明的薄弱点。AI 区分考查知识、疑似卡点、前置基础，引用输入中的连续原文；疑似卡点必须引用学生解法。空白作答不能据此判定知识缺陷。输出有字段和目录校验，推理仍可能错误，需要核对。

不存在的知识 ID 进入待补清单，不生成虚假课程链接。缺口按学科和名称聚合，保留原题来源，供人工审议；不会自动修改知识库。手动修正、重新分析或删除原题后，清单随当前记录更新。

提示、实验辅助和不确定答案不计为独立通过。专项复核与原题自评分开记录，一次答对不等于长期掌握。图形观察不能替代数学证明，物理关系必须满足相应模型条件。

## 代码结构

| 文件 | 职责 |
| --- | --- |
| `js/curriculum.js` | 学科注册、稳定知识 ID、范围、前置依赖、资源路由 |
| `js/course-menu.js` / `course-menu.css` | 三个页面共用的学科切换、课程菜单与手机折叠 |
| `js/learning-store.js` | 带版本的本地存储、错题去重、缺口聚合、备份 |
| `js/llm.js` | API 配置、请求、取消/超时、输出和证据校验 |
| `js/learning.js` | 错题、设置、缺口、导入导出交互 |
| `js/learning-bridge.js` | 原实验与专项的错题收集、来源链接、复核回写 |
| `js/topics.js` | 7 个实验的教学内容 |
| `js/app.js` / `js/draw.js` / `js/utils.js` | 实验流程、绘图、公共工具 |
| `training-data.js` / `training.js` | 原有数理练习与公共分支、持久化、实验台 |
| `science-data.js` / `js/science-labs.js` | 化学、生物练习与守恒/杂交模型 |
| `learning.html` / `index.html` / `training.html` | 错题入口、实验、专项 |

新增知识先在目录声明学科、稳定 ID、覆盖范围、前置依赖和资源，再提供核验过的内容与练习。化学、生物已有入门专题，未覆盖的知识仍进入待补清单。内容说明与来源见 [SCIENCE-GUIDE.md](SCIENCE-GUIDE.md)。不要重用已有 ID，旧错题和链接依赖它。内容版本与存储版本分开，未来引入后端可替换存储及 API 层。

## 运行与部署

原生 HTML/CSS/JavaScript，无构建步骤。建议静态服务器运行，避免 file:// 的存储和跨域差异。例如安装 Python 后执行 `python -m http.server 8080`，打开 `http://localhost:8080/learning.html`。

GitHub Pages：上传所有页面、CSS、JS、.nojekyll，选择对应分支根目录发布，支持项目子路径。不要把密钥写入仓库。

## 验证

```text
node tests/verify.cjs
node tests/learning.cjs
node tests/science.cjs
node tests/browser.cjs
```

前三项无依赖。浏览器测试需要 Playwright 和浏览器，可通过 NODE_PATH 指向已有 Playwright；系统 Edge 可设置 BROWSER_CHANNEL=msedge。测试启动临时本地服务器，使用隔离浏览器，不访问真实模型服务。

覆盖 60 道题、诊断分支、辅助计分、计算边界、资源路径、目录依赖、密钥排除、API 错误和取消、证据校验、未知知识点、刷新恢复、复核回写、备份恢复、HTML 注入防护、移动布局和新旧深链接。截图保存在 tests/*-preview.png（Git 忽略）。实际供应商兼容性与分析质量需要用户配置后验证。
