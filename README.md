# That’s My Boy! · 数理探索实验室

**每一次尝试，都值得鼓励。**

这个项目起源于一位父亲给儿子的鼓励，也欢迎每一个愿意探索的学习者。

面向高中一年级学生，以人教版相关知识主题为范围，通过数形结合、参数实验和选择题反馈，训练“预测 → 实验 → 解释 → 迁移”的思考过程。本项目为独立教学辅助工具，非教材官方配套产品，不含教材扫描件。

## 立即部署到 GitHub Pages

1. 在 GitHub 创建公开仓库，名称建议为 `thats-my-boy`。
2. 解压本项目 ZIP。进入解压后的文件夹，将其中的文件上传到仓库根目录。**不要只上传 ZIP，也不要将整个外层文件夹作为一层子目录上传。**
3. 确认仓库首页直接能看到 `index.html`、`style.css` 和 `app.js`。
4. 打开仓库 **Settings → Pages**。
5. 在 **Build and deployment → Source** 选择 **Deploy from a branch**。
6. 分支选择 **main**，目录选择 **/(root)**，点击 **Save**。
7. 等待发布完成，在 Pages 页面打开网站地址。常见格式为 `https://你的用户名.github.io/thats-my-boy/`。

`.nojekyll` 是随包附带的空文件，用于明确按静态文件发布。系统若隐藏点文件，仍可先上传三个网页文件及 README、LICENSE；本项目不含必须依赖该标记的下划线目录。

以后更新仓库内的网页文件，GitHub Pages 会自动重新发布。免费账号请使用公开仓库。

- https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages
- https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 本地使用

直接双击 `index.html`，用现代桌面浏览器打开即可。无需 Node.js、依赖安装、编译或数据库。所有资源均随项目提供，没有外部字体、CDN 或 API 依赖，也可离线使用。

## 七个专题

| 学科 | 专题 | 交互内容 |
| --- | --- | --- |
| 数学 | 集合与集合运算 | 在韦恩图内拖动元素，切换交集、并集、A 的补集 |
| 数学 | 二次函数的参数 | 调整 a、b、c，观察顶点、开口与函数图像 |
| 数学 | 方程与不等式 | 调整 k，观察 x²=k 的交点和不等式解集 |
| 数学 | 单调性与奇偶性 | 切换函数，比较 f(x) 与 f(−x) |
| 物理 | 路程与位移 | 改变往返距离，对比路程、位移及方向 |
| 物理 | 匀变速直线运动 | 调整初速度、加速度、时间，播放与逐步观察 x–t、v–t 图 |
| 物理 | 力、质量与加速度 | 控制左右作用力和质量，观察合力与加速度 |

## 使用方式

1. 左侧选择专题，右侧先作出预测。
2. 点击“带着预测，开始实验”，解锁实验控件。
3. 调整滑块或拖动元素，观察图形与数值变化。
4. 用“保留对比”保留一组结果；二次函数还会显示之前的虚线图像。
5. 查看结论，完成原因解释与迁移挑战。

集合元素也支持“先点击数字，再点击目标区域”的操作。每个专题包含一组预测、解释和迁移题，并非完整题库。当前覆盖精选知识主题，不是高中教材全部内容。

## 项目结构

- `index.html`：页面结构和元信息。
- `style.css`：桌面优先的样式及响应式布局。
- `app.js`：专题数据、训练流程、SVG 绘图与交互计算。
- `.nojekyll`：GitHub Pages 静态发布标记。
- `LICENSE`：MIT 开源许可证。

使用原生 HTML、CSS、JavaScript 和 SVG。网站不包含账号、后端服务、AI 点评、分析统计或学习记录持久化。刷新页面会重置当前实验。

## 教学边界与验证

交互实验用于观察和提出猜想，不能替代数学证明。物理实验使用各专题注明的理想条件。图形视窗有限，部分曲线可能超出显示范围；读数通常保留两位小数，不能将近似值当作精确结果。

已完成 JavaScript 语法检查、七个专题训练状态检查，以及集合运算、退化二次函数、方程边界、负位移、反向运动和零加速度等核心计算检查。尚未完成真实浏览器端到端测试；发布后建议先体验拖拽、滑块、播放和答题流程。
